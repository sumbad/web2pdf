# Web2PDF

[English](./README.md) | Русский

Утилита командной строки для конвертации веб-сайтов в PDF документ. Она получает страницы сайта через sitemap, конвертирует каждую страницу в PDF с помощью headless Chrome и объединяет все страницы в один файл.

## Возможности

- 🌐 Автоматическое обнаружение страниц через sitemap.xml
- 🖨️ Конвертация HTML в PDF с использованием Chromium/Chrome
- 📚 Объединение нескольких PDF в один документ с закладками
- 🧹 Удаление нежелательных элементов (реклама, уведомления о cookies, футеры)
- 🧩 Платформенные адаптеры (например, для mdBook-документаций)
- 🎨 Принудительная светлая тема для документаций
- 📋 Проброс `console.*` страниц в логи утилиты
- 🔧 Кросс-платформенная поддержка (macOS, Linux, Windows)

## Установка

### Требования

- Chromium или Google Chrome

### Использование установщиков

```bash
# Linux / macOS (через install.sh)
curl --proto '=https' --tlsv1.2 -LsSf https://github.com/sumbad/web2pdf/releases/latest/download/web2pdf-installer.sh | sh
```

```bash
# Windows (через install.ps1)
powershell -ExecutionPolicy Bypass -c "irm https://github.com/sumbad/web2pdf/releases/latest/download/web2pdf-installer.ps1 | iex"
```

### Использование cargo install (для пользователей Rust)

```bash
cargo install --git https://github.com/sumbad/web2pdf.git web2pdf
```

Готовые бинарные файлы доступны на странице [GitHub Releases](https://github.com/sumbad/web2pdf/releases) для:
- macOS (Intel и Apple Silicon)
- Linux (x86_64)

## Использование

### Базовый синтаксис

```bash
web2pdf <URL> [ВЫХОДНОЙ_ФАЙЛ]
```

### Опции

- `--login`, `-l` - Запустить авторизацию (после её прохождения информация будет записана в локальный профиль браузера)
- `--debug`, `-d` - Включить режим отладки с подробным логированием (в debug сборках ограничивает страницы до 3, дампит HTML страниц-источников)
- `--help`, `-h` - Показать справку
- `--version`, `-V` - Показать версию

### Авторизация

Для сайтов за системой авторизации сначала выполните вход:

```bash
web2pdf --login https://example.com
```

Откроется окно браузера — авторизуйтесь и нажмите Enter в терминале. Данные сессии сохранятся в локальном профиле (`~/web2pdf/chrome-profile`) и будут автоматически переиспользоваться при последующих конвертациях.

### Примеры

```bash
# Конвертировать веб-сайт в PDF (по умолчанию output.pdf)
web2pdf https://example.com

# Указать имя выходного файла
web2pdf https://example.com site.pdf

# Сайты с авторизацией: однократно выполнить вход
web2pdf --login https://example.com

# Затем конвертировать как обычно — профиль переиспользуется
web2pdf https://example.com

# Включить режим отладки
web2pdf --debug https://example.com
```

### Как это работает

1. **Обнаружение браузера** - Находит Chromium/Chrome в PATH или стандартных путях
2. **Профиль авторизации** - Если сессия настроена через `--login`, страницы открываются с сохранёнными cookies
3. **Получение sitemap** - Загружает sitemap.xml с указанного URL
4. **Фильтрация страниц** - Исключает нежелательные страницы (подписка, опечатки, колофон)
5. **Конвертация в PDF** - Создает PDF для каждой страницы через headless браузер, дождавшись полной загрузки контента
6. **Объединение** - Комбинирует все PDF файлы в один документ с закладками

## Разработка

### Структура проекта

```
src/
├── main.rs             # Основная логика приложения с парсингом CLI
├── auth.rs             # Авторизация и профиль браузера
├── browser_utils.rs    # Конфигурация и поиск браузера
├── toc.rs              # Генерация оглавления
├── _pdf_utils/         # Утилиты для работы с PDF
│   ├── merge_pdfs.rs   # Реализация объединения PDF
│   ├── sanitize_pdf.rs # Очистка структуры PDF/UA
│   └── helpers.rs      # Вспомогательные функции для структуры PDF
├── _adapters/          # Адаптеры для разных форматов контента
│   └── _mdbook/        # Адаптер для документации MdBook
└── _adapter_registry/  # Система регистрации адаптеров
js/
├── flatten-shadow-dom.js # Обработка Shadow DOM
├── iconify-icon.js       # Обработка иконок Iconify
├── lang-set.js           # Установка языка
├── mdbook-sanitation.js  # Подготовка mdBook страниц
├── page-cleanup.js       # Очистка страниц
├── page-wait.js          # Ожидание загрузки
├── prepare-habr.js       # Подготовка страниц Habr
└── title-extract.js      # Извлечение заголовков
```

### Ключевые зависимости

- `chromiumoxide` - Управление headless Chrome через CDP
- `reqwest` - HTTP клиент для получения sitemap
- `lopdf` - Манипуляция PDF документами
- `quick-xml` - Парсинг XML sitemap
- `tokio` - Асинхронная среда выполнения
- `clap` - Парсинг аргументов командной строки с подсказками и цветным выводом
- `scraper` - Парсинг HTML
- `tracing`/`tracing-subscriber` - Структурированное логирование
- `anyhow` - Обработка ошибок

## Ограничения

- Некоторые сайты с большим количеством JavaScript могут отображаться некорректно
- Сайты с авторизацией требуют предварительного входа через `--login`
- Тяжёлые SPA-страницы конвертируются дольше: утилита ожидает рендер контента перед печатью
